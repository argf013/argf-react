# argf-react

**argf-react** is a collection of reusable React components, built with
TypeScript and Vite.

## Available Components

1. **Accordion**
2. **Avatar** & **AvatarGroup**
3. **Badge**
4. **Button**
5. **Card**
6. **Dialog**
7. **DialogConfirm**
8. **Dropdown**
9. **Input**
10. **Menu**
11. **Skeleton**
12. **Switch**
13. **Tabs**
14. **Toast**

## Installation

To install, run the following command:

```sh
pnpm install argf-react
```
